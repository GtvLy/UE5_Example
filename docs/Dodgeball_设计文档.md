# Dodgeball 游戏设计文档

## 1. 项目概述

**Dodgeball（躲避球）** 是一款基于 Unreal Engine 5 的第三人称动作/生存类游戏。玩家操控一个角色在关卡中移动、跳跃、闪避，躲避由 AI 敌人持续投掷的躲避球。角色拥有生命值，被球命中会损失生命，生命归零即失败并弹出重开界面；玩家需要坚持生存并抵达关卡中的胜利区域以获得胜利。

本项目为教程书籍配套练习项目，使用 UE 的第三人称游戏模板（Third Person Template）作为起点，在此基础上逐步实现自定义角色、生命系统、敌人 AI、投射物、UI 与音频。

## 2. 游戏目标与核心玩法循环

**核心玩法循环：**

```
观察敌人 → 预判/闪避来球 → 保持生命 → 抵达胜利区域
```

- **目标**：在被敌人投掷的躲避球击倒之前，抵达 `VictoryBox` 胜利区域（触发即退出游戏，代表胜利）。
- **失败条件**：生命值（HP）降为 0，角色死亡，弹出重开/退出界面。
- **压力来源**：敌人通过视线检测持续锁定玩家并投掷可反弹的躲避球。

## 3. 玩家体验与操控

### 3.1 视角与操作

| 输入 | 动作 |
|------|------|
| 移动（WASD / 手柄左摇杆） | 第三人称移动 |
| 视角（鼠标 / 手柄右摇杆） | 环绕视角控制 |
| 跳跃 | 跳跃 |

- 采用第三人称跟随相机（弹簧臂 SpringArm + 相机），相机相对角色俯视约 70°，臂长 900cm，适合观察来球方向。
- 移动速度 500cm/s，跳跃初速 500cm/s，空中控制系数 0.35。

### 3.2 移动手感

- 角色朝向随移动方向旋转（`bOrientRotationToMovement`）。
- 标准行走/跳跃手感，便于快速躲避。

## 4. 核心机制

### 4.1 生命系统（Health）

- 玩家拥有 100 点生命值。
- 被躲避球命中时损失 34 点生命（伤害值可在蓝图中调整）。
- 生命值实时显示在 HUD 血条上。
- 生命归零触发死亡事件：弹出重开界面、暂停游戏、切换为 UI 输入模式。

### 4.2 视线检测（Line-of-Sight）

- 敌人通过 `LookAtActorComponent` 每帧检测能否"看到"玩家。
- 视线检测基于自定义碰撞通道（`ECC_GameTraceChannel2`）的射线追踪（Line Trace），并忽略自身与目标。
- 只有在能看见玩家时，敌人才开始投掷躲避球；视线被遮挡（如墙体）时停止投掷。

### 4.3 躲避球投射物（Dodgeball Projectile）

- 物理模拟的弹性球体，碰撞半径 35cm。
- 初速/最大速度 1500cm/s，可反弹（弹性系数 0.3）。
- 命中玩家时扣除生命、播放命中粒子与音效，随后销毁。
- 落地/撞击产生反弹音效（当冲击力超过阈值时）。
- 投射物 5 秒后自动销毁。

### 4.4 胜利与重开

- **胜利**：玩家进入 `VictoryBox` 触发重叠，调用 `QuitGame` 退出。
- **失败重开**：玩家死亡后弹出 `RestartWidget`，提供"重新开始"与"退出"按钮；重新开始会移除 UI、恢复游戏、切换回游戏输入模式。

## 5. 角色与敌人

### 5.1 玩家角色（DodgeballCharacter）

- 基于第三人称模板角色，附加 `HealthComponent` 生命组件。
- 实现 `IHealthInterface` 接口，响应伤害与死亡。
- 死亡时通知 PlayerController 弹出重开界面；受伤时刷新 HUD 血条。

### 5.2 敌人角色（EnemyCharacter）

- AI 敌人（`ACharacter` 派生），携带 `LookAtActorComponent`。
- 行为：每帧检测玩家；当首次看见玩家时启动投掷计时器（每 2 秒投掷一次，初始延迟 0.5 秒）；失去视线时清除计时器。
- 投掷时在自身前方 40cm 处生成躲避球，并将其初速/最大速度提升至 2200cm/s。
- 躲避球类型通过 `TSubclassOf<ADodgeballProjectile>` 在蓝图（`BP_EnemyCharacter`）中指定。

## 6. 关卡设计

- 关卡以第三人称模板地图 `Lvl_ThirdPerson` 为基础，包含：
  - **墙壁（Wall）**：普通障碍物。
  - **幽灵墙（BP_GhostWall）**：可配置碰撞行为的特殊墙体（用于制造"球可穿过、玩家不可穿过"等玩法变化）。
  - **胜利区域（VictoryBox）**：玩家进入即获胜的触发器。
  - **敌人摆放点**：多个 `EnemyCharacter` 分布于关卡中。

## 7. UI / HUD

- **血条（HUDWidget）**：绑定 `UProgressBar`，实时反映玩家生命百分比。
- **重开界面（RestartWidget）**：包含"重新开始"与"退出"两个按钮，玩家死亡时弹出。

## 8. 音频与视觉

### 8.1 音频

- 背景音乐由 `MusicManager`（含 `AudioComponent`）播放。
- 躲避球提供三类音效：反弹音（`BOUNCE`）、命中音（`PUNCH`/`Dodgeball`）、以及背景音乐（`VGMA`）。
- 反弹音使用距离衰减（`SoundAttenuation`）。

### 8.2 视觉

- 命中玩家时在命中点播放粒子特效（`HitParticle`）。
- 使用第三人称模板的 Mannequin 角色与动画。
- 调试阶段在视线检测时绘制红色调试射线（`DrawDebugLine`）。

## 9. 游戏变体（Variant）系统

本项目（以及另两个项目）均内置一套可复用的"游戏变体"框架，包含三种可切换的游戏模式：

1. **Variant_Combat（战斗变体）**：近战连击、蓄力攻击、伤害/死亡/重生、基于 StateTree 的敌人 AI。
2. **Variant_Platforming（平台跳跃变体）**：二段跳、蹬墙跳、冲刺、土狼时间（Coyote Time）。
3. **Variant_SideScrolling（横版卷轴变体）**：横版视角、软平台、交互物、拾取计数 UI。

三个变体各自拥有独立的地图（`Lvl_Combat` / `Lvl_Platforming` / `Lvl_SideScrolling`）与蓝图，可在不同 GameMode 间切换，展示可复用的游戏框架设计。

## 10. 技术选型概览

- **引擎**：Unreal Engine 5.6
- **输入**：Enhanced Input（增强输入）
- **AI**：基础敌人使用计时器 + 视线检测；变体战斗/横版使用 StateTree
- **UI**：UMG（Unreal Motion Graphics）
- **音频**：USoundBase / AudioComponent / 距离衰减
